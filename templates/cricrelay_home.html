Live scores from Play-Cricket — without a heavy broadcast stack

CricRelay is built for UK clubs who stream on YouTube or similar: your Play-Cricket fixture is scraped on a short interval, JSON lands in your relay, and the same browser overlay Prism already uses stays in sync — or you fall back to manual scoring from the pitch.

How it works

Each club has its own Play-Cricket host (for example https://bmacc.play-cricket.com) and each fixture has a numeric match_details?id=…. CricRelay stores your club profile, squads (1st XI, 2nd XI, T20, and so on), and per-fixture relay rows.

When you start a relay, we give you a stable overlay URL for Prism and an ingest URL for your EC2 scraper (for example every 10 seconds). Manual operators can still use the scorer UI.

For broadcasters

  • Register your club once (Play-Cricket base URL + contact).
  • Add squads under your profile.
  • For each stream, add the match id (and optional base URL override); copy the Prism overlay link and scraper ingest URL from the dashboard.
