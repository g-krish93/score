Tournament → live stream

Score a tournament match using your own scoring system and stream it live — no Play-Cricket dependency.

  1. Create a tournament and add teams in Tournaments.
  2. Add a match and click Start Scoring to open the ball-by-ball scorer.
  3. Come back here and add the match as a Tournament stream below — the overlay updates live as you score.
  4. In OBS: add the overlay URL as a Browser Source.
